# 🌿 Life Upupup

> 一个高度模块化的个人生活自我管理平台 · v1.8

---

## 📌 简介

Life Upupup 是一款专为个人打造的生活管理工具，帮助你系统地记录和追踪生活的方方面面——读书、纪录片、身材、饮食、理财、股票学习、语言学习……

核心功能已全部就绪。更多功能正在路上，敬请期待 🚀

---

## ✨ 当前功能

| 模块 | 功能 |
|------|------|
| ✅ 任务管理 | 今日 / 本周 / 本月 / 本年四个独立模块，支持前后时段切换，增删改查 |
| 📚 读书 | 书单管理、阅读状态、评分、心得、读完日期默认今天、CSV 批量导入 |
| 🎬 纪录片 | 观影记录、在看/已看/想看状态、评分、观后感、CSV 批量导入 |
| ⚖️ 身材管理 | 体重 & 围度记录、折线图趋势 |
| 🥗 饮食管理 | 三餐记录（可编辑）、饮水打卡（自定义目标、±1杯）、营养品&药物记录、历史记录按月浏览 |
| 💰 理财管理 | 收支流水按月浏览、资产总览（多币种饼图、折合日元/人民币双汇总）、资产可关联投资记录自动同步余额、实时汇率换算 |
| 📊 投资记录 | 美股/日股/A股/基金四个独立分类，每日记录余额与资金变动（追加/提现自动剔除），真实盈亏计算，折线图走势，总览卡片可跳转分类 |
| 📈 股票学习 | 持仓追踪、观察池（含每日高低点时间）、学习笔记 |
| 🌐 语言学习 | 动态添加/删除语言，每种语言独立模块：每日打卡、日历视图、学习目标、资源收藏 |

- **后端**：Python · FastAPI · SQLAlchemy · SQLite

## 🚀 安装 & 启动

### 环境要求

- Python 3.9+
- Node.js 18+

### 第一步：安装后端依赖

```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 第二步：安装前端依赖

```bash
cd frontend
npm install
```

### 第三步：启动

**方式一（推荐）：一键启动**

直接双击项目根目录下的 `启动.command`（macOS）

**方式二：手动启动**

打开两个终端分别运行：

```bash
# 终端 1 — 后端
cd backend
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2 — 前端
cd frontend
npm run dev
```

启动后在浏览器打开：**http://localhost:5173**

### v1.8 更新详情

- **与投资记录联动**：资产条目可关联投资分类（基金/A股/日股/美股），金额自动取投资记录最新余额，无需手动维护，显示「🔄 实时同步」
- **双币种汇总**：总资产同时显示折合日元与折合人民币两张卡片
- **去除负债模块**：简化页面，专注资产管理
- **饼图优化**：缩小饼半径、增加容器高度，标签不再被遮挡；百分比同步显示在下方列表
