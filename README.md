# 🌿 Life Upupup

> 一个高度模块化的个人生活自我管理平台 · v1.3

---

## 📌 简介

Life Upupup 是一款专为个人打造的生活管理工具，帮助你系统地记录和追踪生活的方方面面——读书、纪录片、身材、饮食、理财、股票学习、语言学习……

这是 **v1.0 基础版本**，核心功能已全部就绪。更多功能正在路上，敬请期待 🚀

---

## 🚀 安装 & 启动

### 环境要求

- Python 3.9+
- Node.js 18+

### 第一步：安装后端依赖

```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 第二步：安装前端依赖

```bash
cd frontend
npm install
```

### 第三步：启动

**方式一（推荐）：一键启动**

直接双击项目根目录下的 `启动.command`（macOS）

**方式二：手动启动**

打开两个终端分别运行：

```bash
# 终端 1 — 后端
cd backend
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2 — 前端
cd frontend
npm run dev
```

启动后在浏览器打开：**http://localhost:5173**

### v1.2 更新详情

**任务模块全面重构**

- **四个独立模块**：今日任务 / 本周任务 / 本月任务 / 本年任务，数据彼此完全隔离，互不干扰
- **时段切换导航**：每个模块均可前后切换（上一天 / 下一天、上一周 / 下一周、上个月 / 下个月、上一年 / 下一年），历史与未来时段均可查看和记录
- **快速返回**：偏离当前时段时，一键"回到今天 / 本周 / 本月 / 今年"
- **完整增删改**：任务支持添加（含模块标签）、勾选完成、内联编辑标题与标签、删除
- **侧边栏重构**：任务四个子模块作为独立导航条目，与其他模块对齐

**Bug 修复**

- 修复切换到非今日时段后无法添加任务的问题（SQLAlchemy Date 类型不接受字符串）
- 修复编辑任务标签后无法保存的问题（pydantic exclude_unset 逻辑 + 变量遮蔽）
- 修复后端 uvicorn 未热重载导致新路由不生效的问题，启动脚本加入 `--reload`

### v1.3 更新详情

**读书模块完善**

- **CSV 批量导入**：支持一次性导入多本书籍，字段包含书名、状态、评分、标签、读完日期、心得
- **下载导入模板**：一键下载标准 CSV 模板，按格式填写后直接导入，导入后显示成功/失败数量
- **读完日期默认今天**：新增或编辑书籍时，状态切换为「读完」自动填入今天日期，无需手动选择
