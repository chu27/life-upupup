# 🌹 Life Upupup

> 一个高度模块化的个人生活自我管理平台 · v2.1

---

## 📌 简介

Life Upupup 是一款专为个人打造的生活管理工具，帮助你系统地记录和追踪生活的方方面面——读书、纪录片、身材、饮食、价格管理、理财、投资记录、持仓股票、语言学习……

核心功能已全部就绪。更多功能正在路上，敬请期待 🚀

---

## ✨ 当前功能

| 模块 | 功能 |
|------|------|
| ✅ 任务管理 | 今日 / 本周 / 本月 / 本年四个独立模块，支持前后时段切换与日历跳转，模块标签可自定义增删改，增删改查 |
| 📚 读书 | 书单管理、阅读状态、评分、心得、读完日期默认今天、CSV 批量导入 |
| 🎬 纪录片 | 观影记录、在看/已看/想看状态、评分、观后感、CSV 批量导入 |
| 📈 持仓股票 | 美股/日股/A股 市场筛选，实时/历史价格查询，高低点时间（JST），近30天~1年高低点时段分布图 |
| ⚖️ 身材管理 | 体重 & 围度记录、折线图趋势、锻炼打卡（连续天数 / 本月打卡日历 / 多种运动类型） |
| 🥗 饮食管理 | 三餐记录（可编辑）、饮水打卡（自定义目标、±1杯）、营养品&药物记录、历史记录按月浏览 |
| 🛒 价格管理 | 商品价格记录，支持种类（含「其他」）/产地/税率（8%/10%）/折扣（5%~50%）/数量，固定店铺选择，历史价格涨跌对比 |
| 💰 收入 & 支出 | 收支流水按月浏览、支出饼图分类 |
| 🏦 资产总览 | 多币种饼图（日元/美元/人民币各自总额），折合日元/人民币双汇总，资产明细按币种分组，资产可关联投资记录自动同步余额，实时汇率换算 |
| 📊 投资记录 | 美股/日股/A股/基金四个独立分类，现持有 / 清仓分区展示，每日记录余额与资金变动（追加/提现自动剔除并联动对应现金账户余额），真实盈亏计算，累计盈亏折线图，历史日期盈亏查询 |
| 🌐 语言学习 | 动态添加/删除语言，每种语言四大标签模块：**首页**（每日打卡、日历视图、学习目标、资源收藏）、**语法**、**单词**、**句子**，均支持掌握度标记与粘贴批量导入 |

## 🚀 安装 & 启动

### 环境要求

- Python 3.9+
- Node.js 18+

### 第一步：安装后端依赖

```bash
cd backend
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 第二步：安装前端依赖

```bash
cd frontend
npm install
```

### 第三步：启动

**方式一（推荐）：一键启动**

直接双击项目根目录下的 `启动.command`（macOS）

**方式二：手动启动**

打开两个终端分别运行：

```bash
# 终端 1 — 后端
cd backend
source venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2 — 前端
cd frontend
npm run dev
```

启动后在浏览器打开：**http://localhost:5173**

### 局域网访问（手机等设备）

前端已配置 `host: true`，同一 WiFi 下其他设备可通过电脑局域网 IP 访问：

```
http://<电脑IP>:5173
```

### v2.1 更新详情

**语言学习多模块化**

- **四大标签**：每种语言页面拆分为「首页 / 语法 / 单词 / 句子」四个标签
  - 语法：语法点 + 说明 + 例句
  - 单词：单词 + 读音（假名/拼音）+ 释义 + 例句
  - 句子：句子 + 中文意思 + 备注笔记
- **掌握度标记**：每条目标记「未学 / 学习中 / 已掌握」，徽章点击即可快速循环切换
- **粘贴批量导入**：每行一条、逗号分隔字段，一次性导入多条，兼容中文逗号 / 英文逗号 / 制表符（可从 Excel 直接复制）
- **新增语言自动识别**：输入语言中文名时自动补全英文 code 与国旗 emoji（两者均改为选填）

**身材管理新增锻炼打卡**

- 多种运动类型（跑步 / 力量训练 / 瑜伽 / 游泳等），记录时长与备注
- 连续打卡天数、本月打卡次数统计，本月打卡日历可视化

**投资记录优化**

- **资金变动联动现金账户**：填写资金变动时，对应现金账户自动反向增减（A股↔股票现金、基金↔支付宝活期、美股↔SBI美元账户、日股↔SBI日元账户），加钱减少现金、提现增加现金，编辑只应用差额、删除自动撤销
- **现持有 / 清仓分区**：昨日金额为 0 的条目自动归入「清仓」区，与持仓分开展示，持仓再按币种分组
- **累计盈亏修复**：清理每日重复记录、前后端均加按日期去重，修复折线图盈亏异常跳变

**首页 & 任务自定义**

- **快速入口可自定义**：首页快速入口支持用户自由增删（最多 6 个），本地保存
- **任务模块标签自定义**：标签支持增 / 删 / 改，各时段新增日历日期选择器

**资产总览**

- **资产明细按币种分组**：明细列表按日元 / 美元 / 人民币分组展示，各组独立小计

### v2.0 更新详情
