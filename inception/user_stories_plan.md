## 项目概述

一个高度模块化的个人生活管理平台，涵盖读书、纪录片、身材、理财、股票学习、日语学习等生活方方面面，帮助用户系统记录、回顾和提升自我。

#### 3.1 读书模块
- [ ] 需求访谈（见下方问题）
- [ ] 起草用户故事
- [ ] 用户审查确认

**[Question 3.1-1]** 读书记录想保存哪些信息？  
**[Answer 3.1-1]** 书名、读完日期、阅读状态（在读/读完/想读）、我的评分（1-5星）、心得感悟（长文）、书籍分类/标签。

**[Question 3.1-2]** 是否需要统计图表？  
**[Answer 3.1-2]** 暂时不需要。

**[Question 3.1-3]** 录入书籍时自动搜索还是手动填？  
**[Answer 3.1-3]** 通过本地文件录入（由用户提供文件）。

#### 3.2 纪录片模块
- [ ] 需求访谈（见下方问题）
- [ ] 起草用户故事

**[Question 3.2-1]** 纪录片记录想保存哪些信息？  
**[Answer 3.2-1]** 片名、观看日期、观看平台、我的评分、心得感悟（长文）、视频链接、分类/标签（自然/历史/人文……）、观看状态（已看/想看）。

**[Question 3.2-2]** 视频链接是跳转外部还是内嵌播放？

#### 3.4 理财管理模块
- [ ] 需求访谈
- [ ] 起草用户故事
- [ ] 用户审查确认

**[Question 3.4-1]** "记录经济状况"核心需求是哪些？  
**[Answer 3.4-1]** A. 日常收支记账、B. 资产总览（存款/基金/股票/现金）、C. 月度/年度预算与超支预警、E. 财务目标（如存够5万元）。资产总览、预算追踪、财务目标均需配套多种可视化图表，用户可自选图表类型。

**[Question 3.4-2]** 是否需要收支分类并生成分类饼图/柱状图？  
**[Answer 3.4-2]** 需要支出分类并生成分类饼图/柱状图。

#### 3.5 股票学习模块
- [ ] 需求访谈
- [ ] 起草用户故事
- [ ] 用户审查确认

**[Question 3.5-1]** 这个模块的定位是什么？  
**[Answer 3.5-1]** A. 学习笔记（K线、指标、技术分析心得）、B. 持仓跟踪（买了哪些股票、买入价、当前盈亏）、D. 股票观察池（感兴趣的股票加自选、备注分析）。三个子功能均需 AI 辅助设计（分析建议、笔记整理、观察池点评等）。

**[Question 3.5-2]** 是否需要接入实时股价？  
**[Answer 3.5-2]** 需要接入实时股价，并记录当天最高点/最低点出现的时间及收盘价。后续需要多种统计图，样式待定。

#### 3.6 日语学习模块
- [ ] 需求访谈
- [ ] 起草用户故事

**[Question 3.6-1]** 日语/英语学习模块核心功能？（日英共用同一结构）  
**[Answer 3.6-1]** A. 每日学习打卡（时间/内容，可备注所用第三方App）；D. 学习资源收藏（教材/网站/YouTube链接）；E. 学习目标与进度（JLPT N2 / 英语六级备考进度）。

**[Question 3.6-2]** 日语和英语是否用同一套结构？

**[Question 3.6-3]** 是否需要复习提醒？

#### 3.8 饮食管理模块
- [ ] 需求访谈
- [ ] 起草用户故事
- [ ] 用户审查确认

**[Question 3.8-1]** 饮食管理最核心要记录什么？  
**[Answer 3.8-1]** A. 每日饮食日记（今天吃了什么，文字记录，手动输入；含最近饮食提醒）；B. 卡路里/营养素追踪（需接入AI，根据用户提供的食物做法和重量自动计算热量/蛋白质/碳水）；C. 饮水量记录。

**[Question 3.8-2]** 卡路里计算方式？  
**[Answer 3.8-2]** 需要食物数据库 + AI计算：用户提供完整做法和食材重量，AI帮助计算营养素。

## 补充确认

**[Question 补充-1]** 首页"今日任务"是独立模块还是汇总提醒？

**[Answer 补充-2]** 书籍文件本身（PDF 或其他文本格式），上传后系统解析并录入书籍信息。
